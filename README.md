## Deskripsi Program
Aplikasi berbasis *command-line interface* (CLI) dalam bahasa C ini dirancang untuk mempermudah operasional usaha penyewaan perlengkapan berkemah **Adventure Camp**. Program dibangun dengan pendekatan pemrograman terstruktur menggunakan fungsi dan *array* untuk menangani berbagai transaksi secara interaktif dalam satu kali sesi jalan.

**Fitur utama yang tersedia dalam program ini meliputi:**
1. **Daftar Peralatan:** Menampilkan katalog peralatan camping beserta tarif sewa harian.
2. **Transaksi Penyewaan:** Memproses input penyewa, memvalidasi jumlah unit dan lama hari sewa, serta menerapkan potongan diskon otomatis (10% untuk sewa 3–4 hari, 15% untuk sewa ≥ 5 hari).
3. **Cetak Struk:** Menampilkan rincian biaya sewa dan total akhir yang harus dibayarkan.
4. **Riwayat Transaksi:** Menyimpan hingga 10 data transaksi menggunakan *array* dan merekapitulasi total pendapatan keseluruhan.
